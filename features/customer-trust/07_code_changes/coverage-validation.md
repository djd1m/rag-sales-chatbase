## Границы свидетельств

SSR и браузерные дополнения привязаны к точным байтам исходников, bundle и source map. Дополнительные позиции подтверждены настоящими событиями `Debugger.paused` в выделенном Chromium с совпадающими script ID, строкой, колонкой и отображённым токеном. Запрошенный breakpoint или успешное пользовательское утверждение сами по себе не дают покрытой строки. Проверены отрицательные контроли для несовпадения исходника, отсутствующей карты, невызываемой функции и нулевого дочернего диапазона.

Отладочные паузы меняют время выполнения: эти данные не используются как измерение производительности. Выполненная позиция не доказывает все ветви и пути функции.
