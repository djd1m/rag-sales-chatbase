[Соответствующая лицензия AGPL-3.0](https://github.com/abhinavxd/libredesk/blob/f8af161763005454c39d0f6eef8d15bfc2648848/LICENSE). Эти source/license ссылки возвращаются в HTTP Link при доставке неизменённого загрузчика.

Приложение не принимает автоматически новую версию. Серверный proxy без credentials принимает только закреплённые байты; browser SRI проверяет их повторно. Ошибка сети или новый digest закрывают чат с понятным состоянием. При обновлении нужны повторный аудит исходника, новая константа и отрицательный браузерный тест.

Закреплённый загрузчик входит в доверенный код Суфлёра. Это контроль целостности, а не изоляция JavaScript отдельным browser principal. Собственный origin вложенного диалога, проверка source/origin сообщений, запрет автоматической передачи page URL/title и текущая authority дополняют границу. Совпадение загрузчика не доказывает версию backend/iframe или фактическую фильтрацию истории отдельного inbox; это проверяется при активации с ключами.
