# Отчёт реализации

- `packages/rag/src/providers.ts`: явные независимые провайдеры, закрытые пары моделей и фиксированные
  адреса; DeepSeek Responses JSON Schema, thinking off; Cloud.ru embeddings.
- `gateway.ts`: общий транспорт и очищенные ошибки, запрет редиректов, индексированные векторы.
  `openrouter.ts`: прежний протокол сохранён, разбор/транспорт переиспользованы (ADR-012/024).
- `config.ts`, web/worker runtime и probes: отдельные ключи; worker загружает только embeddings.
  Общий embedding-env по-прежнему содержит FM и OR поля, даже если один не выбран; DeepSeek ключ
  передаётся только web. Обратное переключение не требует правки кода.
- Учёт попыток дополнен provider. Формат не является бухгалтерией USD/RUB; квоты, fsync, retry rules,
  порог, top-4, фильтр bot_id и проверка цитат сохранены.
- Compose/шаблоны/приватный VPS env/VPS check: выбран гибрид; новые секреты оставлены пустыми,
  чужие ключи не копировались. Инструкция возврата — `deploy/vps/README.md`.
- Адаптированы сетевые фикстуры: стандартный index присутствует у каждого вектора. Добавлены
  проверки всех сочетаний, отказов/проб/квот/цитат, VPS конфигурации и три мутации.
- В `.dockerignore` восстановлен последний приоритет `!docs/canon.md`: старый тест ожидал его
  последним после добавленных при standalone-импорте исключений секретов. Защита секретов сохранена.

Новая модель эмбеддингов/1024 измерения, автопереключение, калибровка и измерение качества не реализовывались.
