# Проверка исправления

## Прогоны до изменения кода

- K1 проекта вернул 0 для нового имени модуля `next-targets.test` и проверочного имени `maskNextDynamicDirectories` после просмотра 221 файла и 7 манифестов. Исходный `dz name-check` вернул 2 из-за структуры репозитория. Отдельный поиск по проектным инструментам до патча совпадений не нашёл.
- Исходный K2 с `--tier=S --require-requirements` вернул exit 0 на плане исправления до правки парсеров. Нативный `check-code-targets.mjs` допустил цели этого плана.
- Исходный K2 вернул exit 1 на изолированном плане с двумя реальными путями. C3 признал `apps/web/src/app/preview/[jobId]/PreviewScreen.tsx` и `apps/web/src/app/dashboard/bots/[botId]/BotScreen.tsx` остатком Markdown. Нативный читатель уже допускал эти исходные пути и использовал отдельную проверку границ файла.

## Прогоны после изменения

- Тот же план с двумя реальными путями прошёл K2 (exit 0). C9 прочитал два файла на диске и сообщил ноль незаявленных копий. Нативный `check-code-targets.mjs` вернул `admitted`. В изолированном Git checkout `measureManifest` и `check-review-convergence.mjs prepare` вернули одинаковый снимок с обеими исходными строками и точными SHA-256 файлов.
- Пять групп тестов `node --test tools/feature-process/next-targets.test.mjs` прошли. Покрыты одиночный, catch-all и optional catch-all сегменты, смешанные допустимые и ошибочные строки, Markdown-ссылки, glob, скобки вне маршрута, пробелы, переносы строк, абсолютные пути, traversal и пустой сегмент. C3 отказал каталогу с завершающим `/`, нативный снимок отказал существующему каталогу без `/`.
- В изолированном checkout намеренно пропущенное требование вернуло `FAIL C8`, а отслеживаемая байт-в-байт копия динамического исходника вернула `FAIL C9` с исходным именем. Оба результата наблюдались в одном отклонённом прогоне K2.
- Локальные изменения двух штатных файлов задокументированы по исходным SHA-256. AQE-референсы и их манифест совпадают с поставкой. Предыдущий отчёт о первоначальной настройке относится к срезу до этой адаптации. [Справка об адаптации](../../tools/feature-process/upstream-adaptations.md)
