# Классификация совместимости K2 с маршрутами Next.js

Task kind: bugfix

Tier: S

## Область

Два парсера целей feature-adr и регрессионная проверка для рабочих путей Next.js. Оценка S выбрана для отдельного исправления по заданию координатора. Изменения сосредоточены в инструментах проверки, без новых интеграций, схем данных и изменений продуктовых контрактов.

| Измерение | Балл | Основание |
|---|---:|---|
| Файлы | 2 | Два парсера, тест и справка об адаптации. |
| Домены | 1 | Проверка путей в инструментах разработки. |
| Интеграции | 1 | Используются установленные Node и проектные гейты. |
| Совместимость | 1 | Добавляется точная форма существующего каталога маршрута. |
| Модели данных | 1 | Формат буквальных целевых путей сохраняется. |
| Сквозные свойства | 1 | Область ограничена проверкой путей. |

Сумма 7. Шаги 0 → 1 → 6 → K1/K2 → 7 → 8.

## Acid cases

| ID | Проверяемый отказ или инвариант |
|---|---|
| A1 | Точные существующие динамические пути проекта принимаются и передаются с исходными скобками в нативный снимок. |
| A2 | Markdown-ссылки, звёздочки, разбитые скобки, абсолютные пути, обход каталогов, подставные сегменты и каталоги остаются ошибками. |
| A3 | Ошибки других правил K2, включая незаявленную идентичную копию и отсутствующую задачу требования, сохраняют блокирующий результат. |
