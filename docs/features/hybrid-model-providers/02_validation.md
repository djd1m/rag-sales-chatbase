# Валидация плана

Дата: 2026-11-18. План принят к реализации в рамках прямого запроса владельца.

- Формат DeepSeek проверен по официальной спецификации Responses: `/responses`, `input`,
  `text.format={type:json_schema,name,schema}`, `reasoning.effort=none`, `max_output_tokens`.
  Chat Completions OpenRouter payload не используется для DeepSeek.
- Cloud.ru FM каталог подтверждает endpoint `/v1/embeddings` и модель 3-small; авторизация — FM
  API Key Secret. Протокол оплачиваемого ответа ещё требует живой проверки.
- Размерность/модель эмбеддингов сохранены. Новая SQL-миграция не нужна. При переносе существующего
  индекса между шлюзами требуется проверка совместимости либо полная переиндексация.
- Неизвестные провайдеры, несовместимые модели, пустые выбранные ключи и другая размерность — отказ.
  Невыбранные ключи не обязательны. Отсутствие доказательства качества не подменяется тестами.
- Rollback — явные настройки OpenRouter и пересоздание web/worker; не автоматический вызов резерва.
- Живой VPS запуск и Caddy route не входят в подтверждённый результат без ключей. Тестовая DB/Redis
  изолированы от работающих проектов и удаляются после проверки.

Результаты реализации и проверок — `05_completion.md`; независимое чтение — `08_review.md`.
