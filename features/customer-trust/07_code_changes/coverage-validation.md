## Зафиксированная область

Первоначальные `all:true`-заглушки Vitest ошибочно считали комментарии, пустые строки и стираемые TypeScript-типы исполняемыми строками неимпортированных файлов. Эти отчёты сохранены, но их проценты не используются как фактическое покрытие. Выполненные SSR/default-route контракты дали настоящие преобразованные V8-счётчики; в итоговом текущем unit-отчёте таких заглушек нет.

## Полученные результаты

- Консервативная нижняя граница покрытия добавленных строк: **2027/2150 = 94,28%**, выше порога 80%. Одна известная строка из отдельного source map вне unit-знаменателя включена в эту границу как непокрытая. Точный объединённый процент неизвестен; граница относится к наблюдаемой инструментальной области при предположении полноты её отображения.
- Все файлы фиксированной критической области имеют не менее 90% наблюдаемых строк. Ранее недостающие участки: support-widget **147/162 = 90,74%**, PreviewScreen **118/127 = 92,91%**, PreviewClaimNotice **34/35 = 97,14%**.
- Все **1941/1941** ранее наблюдавшихся покрытыми неизменённых строк имеют текущее подтверждение; потерянных и неотображённых строк нет. Это отдельный строгий наблюдательный критерий сохранения положительных свидетельств.

Сохранение прежних положительных строк само по себе не доказывает сохранения общего процента. Поэтому после завершения нагрузочных процессов выполнен одинаковый дополнительный SSR/import-сценарий на обеих версиях. В 54 существующих файлах baseline получил **2522/3064 = 82,31%**, current — **3210/3556 = 90,27%**. Известных отображённых строк вне этих знаменателей нет. Консервативная верхняя граница baseline ниже нижней current: критерий сохранения наблюдаемого процента **пройден** при явно принятом предположении полноты инструментальных карт. Разные исходные тестовые корпуса и неинструментированные пути не позволяют делать причинный или всеобщий вывод.

На обеих версиях выполнено по **2/2** случая, реальные преобразованные счётчики получены для всех 31 обязательных ранее fallback-файлов. Четыре дополнительных nonfallback-файла с каждой стороны не попали в новый probe; их прежние настоящие счётчики сохранены. Повтор с одинаковым тестовым IP на обеих версиях выполнен в новых артефактах; первоначальный отказ не переписан. SHA-256 общего окончательного probe: `c015c566a6c1280db716e8207715e3b284203bff74c1e3412c12c0a8f52c55ba`.

## Границы свидетельств

SSR и браузерные дополнения привязаны к точным байтам исходников, bundle и source map. Дополнительные позиции подтверждены настоящими событиями `Debugger.paused` в выделенном Chromium с совпадающими script ID, строкой, колонкой и отображённым токеном. Запрошенный breakpoint или успешное пользовательское утверждение сами по себе не дают покрытой строки. Проверены отрицательные контроли для несовпадения исходника, отсутствующей карты, невызываемой функции и нулевого дочернего диапазона.

Последнее подтверждение `chat-window.ts:145` получено на существующем тесте видимого бейджа. При фильтрации выполнен один выбранный случай, остальные 11 не запускались; это не новый полный прогон. Отладочные паузы меняют время выполнения: эти данные не используются как измерение производительности. Выполненная позиция не доказывает все ветви и пути функции.

Инструментированный полный unit-прогон завершился с **1271 успешным, 7 неуспешными и 1 пропущенным** случаем. Отказы временных утверждений и очереди сохранены, этот запуск не объявляется успешным. Независимый полный прогон без профилировщика внутри итогового образа дал **1263/1263**, новые default-route/SSR контракты — **15/15**, полный SQL billing-набор — **23/23**, расширенные браузерные контракты — **18/18**. Эти наборы имеют разную область и не складываются в один заявленный полный результат.

Настоящие почта, новая оплата и поддержка остаются выключенными до ключей и отдельной проверки готовности. Фактическое исследование с пятью людьми не проводилось.
