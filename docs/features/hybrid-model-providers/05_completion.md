# Реализован гибрид DeepSeek + Cloud.ru FM, OpenRouter сохранён

Дата: 2026-11-18. Решение — ADR-024. Рабочий каталог: `/home/rag-sales-chatbase`.

Основной профиль: прямой DeepSeek `deepseek-flash`, Responses JSON Schema, thinking off;
Cloud.ru FM `openai/text-embedding-3-small`, 1536. Явный возврат к OpenRouter и независимое
переключение двух путей описаны в `deploy/vps/README.md`. Приватный .env переведён на гибрид,
новые поля ключей пустые, права 0600. Значения существующих секретов сохранены.

## Проверено

- `npm run build`, `npm run typecheck`, `npm run lint` — успешно в Node 22.
- Полный локальный Vitest: **68 файлов, 1206/1206 тестов**, без пропусков; настоящие изолированные
  PostgreSQL 16 + pgvector 0.8.6 и Redis 7.4. Браузерный набор не запускался (UI не менялся).
- `python3 scripts/test-vps-model-config.py`: **8/8**. VPS check принимает заполненный фиктивный
  гибрид без OR ключа и штатно отказывает приватному .env без выбранных ключей.
- Граф environment/Compose: потерь нет; worker не получает DeepSeek. Общий embedding-env содержит
  оба поля OR/FM, даже при выборе одного (это не отправка ключа другому API).
- Три мутации в отдельной копии: thinking on → **3 failed / 40 passed**; неверный endpoint
  Cloud.ru → **3 failed / 40 passed**; игнорирование index → **1 failed / 42 passed**.
  Восстановлено → **43/43 passed**. Основное дерево при мутациях не менялось.
- Свежие образы `n6-sufler-web:vps`, `n6-sufler-worker:vps`, `n6-sufler-migrate:vps` собраны штатным
  Dockerfile. SHA-256 исходника адаптера в каждом совпадает с рабочим деревом.
- В образах проверены четыре startup-пробы: web/worker × hybrid/OpenRouter, на подменных API.
  Проверены URL, JSON Schema, thinking off, лимит 16, dimensions 1536 и attempt/outcome.
- Независимое read-only ревью: блокирующих runtime-находок нет; два замечания по тестам закрыты,
  узкий повторный проход чистый. Текст — `08_review.md`.
- Подготовленная публичная копия проверена Gitleaks: **0 находок**; .env не отслеживается.

Первый ограниченный прогон: 337 passed / 1 failed — старое позиционное ожидание последней строки
.dockerignore после standalone-импорта. Порядок исключения canon восстановлен; полный прогон выше зелёный.

## Границы результата

Реальных ключей провайдеров нет: **0 платных API-вызовов**. Живые форматы/авторизация/задержка и качество
Haiku против Flash не измерены; равенство качества не заявляется. Межмодельный характер ревью не доказан.
При существующих индексах смена embedding-шлюза требует проверки совместимости либо переиндексации.
Продуктовый VPS-стек и новый TLS-маршрут не запускались; старые сайты/БД/общий Caddy не менялись.
Временные тестовые DB/Redis/сеть, builder-кэш, зависимости и старые образы только этого прогона удалены.
Сырые журналы/идентификаторы образов — `.secrets/hybrid-implementation/`, вне git.

Переиспользование: клиент/ошибки OpenRouter, quota/meteredCall адаптированы из существующего кода
ADR-012; новые Responses/Cloud.ru адаптеры написаны заново по разным API-контрактам. SQL-миграций нет.
