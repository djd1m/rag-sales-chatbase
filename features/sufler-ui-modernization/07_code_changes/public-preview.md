# Публичный предпросмотр интерфейса

[Открыть демо](https://sufler-preview.78.17.53.233.sslip.io/__preview) · [Главная](https://sufler-preview.78.17.53.233.sslip.io/)

Опубликован 25 ноября 2026 года для обсуждения UI до окончательной приёмки. Кнопка на странице входа создаёт отдельный учебный кабинет с ботом «Северный свет». Реальные аккаунты и данные основного `sufler.site` не используются. Почта, поддержка, касса и платежи выключены. Модель и эмбеддинги синтетические; пример ответа не оценивает качество реального RAG.

Проверено через публичный HTTPS с проверкой сертификата: вход и главная 200, создание учебного сеанса 303, заполненный кабинет и карточка бота 200, ответ владельцу 200 со ссылкой на учебный источник. Чужой Origin при создании демо-сеанса получает 403. Это HTTP-проверка, не результат полного браузерного QE.

Предпросмотр обновлён до итогового `n6-sufler-test:trust20261125r4`, идентификатор `sha256:5ff81f7cf8db5a95b17e331151bf4bad91a3d318f93143af8a5ac31f03bba17e`, Next BUILD_ID `R8u2VkzHPZwAUwGc2g6Yn`. Проверено совпадение 299 исходных файлов и 162 файлов пакетов, worker и виджета с образом. В демо вошли исправления буфера обмена, тарифных пояснений и доступности восстановления при отключённой почте. Платежи, почта и чат поддержки демо отключены. Изменения основной версии сайта ещё не опубликованы. [Фактические снимки](../../../docs/ui-ux/modernization-validation-2026-11-25/README.md).

Приложение, worker и данные находятся в отдельной внутренней сети и отдельном Compose-проекте; наружу выведен только шлюз. Только шлюз подключён к общей TLS-двери. Его upstream использует уникальные имена частной сети. Новая публикация ограничена `127.0.0.1:18086` и одним отдельным vhost. У PostgreSQL отдельный том, у загрузок ограниченный tmpfs. Учебные кабинеты ограничены по числу и времени жизни. Рабочие ключи не передаются в этот контур.

Приватные конфигурация и откат хранятся на VPS вне репозитория. Предпросмотр — промежуточный артефакт для обсуждения; результаты приёмки приложения и статус реальных интеграций отражаются отдельно в Step8.
