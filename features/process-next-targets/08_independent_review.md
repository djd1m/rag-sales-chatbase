# Независимая проверка целей Next.js в feature-adr

25 ноября 2026. **PASS для локального Plain-процесса.** Проверены изменения относительно `ba39597`, требования FR-1–FR-3, регрессионные тесты и фактический Step 6 обеих продуктовых фич. Замечаний, требующих исправления в заявленной области, нет.

| Проверка | Независимый результат |
|---|---|
| Воспроизведение дефекта на неизменном UI-плане | K2 из установленной поставки 1.5.26 дал exit 1 и два `FAIL C3` для реальных файлов в каталогах `[jobId]` и `[botId]`. Проектный K2 на тех же байтах плана дал exit 0, без предупреждений и пропусков. |
| Грамматика и точность путей | Замена сегмента применяется только во временном представлении для проверки символов и только к полному каталогу внутри `apps/web/src/app/`. Одиночный параметр, catch-all и optional catch-all с объявленным ASCII-идентификатором сохраняют буквальное написание в результате. На шести дополнительных примерах проверены вложенные динамические каталоги, похожее имя соседнего дерева, скобки в имени файла, ошибочный идентификатор и остаток разметки. Все результаты совпали с ожидаемыми. |
| Регрессии K2 и нативный манифест | На закреплённом Node команда `--test tools/feature-process/next-targets.test.mjs` завершилась с exit 0, прошли 5 из 5 групп. Неверные формы, Markdown-ссылки, glob, абсолютные пути, traversal и пустые сегменты дали отказ. Нативное измерение отклонило существующий каталог. Для двух реальных файлов измерены исходные пути и SHA-256 содержимого, сохранённый снимок prepare совпал с измеренным манифестом. Непокрытое требование и незаявленная отслеживаемая копия по-прежнему дали отдельные FAIL C8 и FAIL C9. |
| Целостность адаптации | Оба заявленных исходных SHA-256 совпали с установленным npm-пакетом. Скрипт convergence совпал с поставкой, все 89 публичных файлов AQE references также совпали побайтно. По UPSTREAM-MANIFEST проверены все 85 записей SHA-256, расхождений нет. |
| Реальный UI Step 6 | `run stage 6 features/sufler-ui-modernization --tier L --change sufler-ui-modernization` вернул 0. K2 проверил 2 ADR, ноль ошибок, предупреждений и пропусков. Ideation convergence сообщил closed для ревизии `80a4f87548dad351fc9a7b1bb6e7c3e95a37c545e3a0da9e4465299d8b070d03`. |
| Реальный customer-trust Step 6 | `run stage 6 features/customer-trust --tier XL --change customer-trust` вернул 0. K2 проверил 3 ADR, ноль ошибок, предупреждений и пропусков. Ideation convergence сообщил closed для ревизии `3bdcaeed42340b3ee1f8050f3a132f453ae8ad24787d4ac5c489498753b70283`. |

Проверка охватывает локальные `run k2`, нативную проверку файлов, convergence и Step 6. Установленный отдельно в harness-core polling barrier сохраняет собственную несовместимую грамматику; ограничение записано в [описании адаптации](../../tools/feature-process/upstream-adaptations.md). Допуск планов относится к указанным ревизиям. На момент проверки Git не показывал изменений в apps и packages.
