для публикации секретов или сырых журналов.

## Как проверено

Gitleaks 8.30.1 установлен из официального релиза с проверкой SHA-256.
Выполнены сканирование всей скопированной папки, дополнительный поиск
приватных ключей, строк авторизации, паролей/токенов, URL с учётными данными,
email/телефонов и ручная классификация найденных мест.
Действующих ключей API или приватных ключей в проверенном тексте не выявлено.
Примеры контактов и паролей относятся к тестовым данным/шаблонам.

Четыре предупреждения Gitleaks относятся к литералам в полностью локальной
оснастке `tests/browser/widget-harness.ts`: HTTP на loopback, боты в памяти и
подставной модельный шлюз. `.gitleaks.toml` разрешает только эти точные значения
и только в этом файле, сохраняя стандартные правила для остальных данных.
Весь файл из проверки не исключается. Контрольная синтетическая строка с новым
API-токеном в том же пути обнаруживается сканером; это проверено отдельно.

Перед отправкой отдельно проверяется снимок **только файлов публикации**
и новая история коммитов. Сырые результаты сканера не публикуются.
Автоматический поиск не доказывает отсутствие любых видов конфиденциальной
информации; здесь проверены текстовые секреты и исключены сырые материалы.
