# Сравнение OpenRouter и Cloud.ru Foundation Models для RAG проекта

На 18.11.2026 Cloud.ru FM подходит как кандидат на единого поставщика ответов
и эмбеддингов. В отличие от прямого API DeepSeek, сервис предлагает обе части RAG.
Можно сохранить нынешние модели либо перейти на модели внутри Cloud.ru.
Это разные решения по обработке данных и объёму изменений.

## Текущие модели и точные аналоги

В проекте настроены следующие модели. Их наличие в каталоге Cloud.ru подтверждено,
но обе там относятся к **внешним**: запросы покидают инфраструктуру Cloud.ru.
Переход к российскому контрагенту сам по себе не переносит их обработку внутрь
Cloud.ru. [Каталог и определение размещения](https://cloud.ru/docs/foundation-models/ug/topics/overview__available__models).

| Компонент | Модель в обоих каталогах | OpenRouter за 1 млн токенов | Cloud.ru FM за 1 млн токенов, с НДС 22% |
|---|---|---:|---:|
| Ответы | `anthropic/claude-haiku-4.5` | $1 вход / $5 выход | 196,42 ₽ вход / 982,10 ₽ выход |
| Эмбеддинги | `openai/text-embedding-3-small` | $0,02 вход | 3,933 ₽ вход |

OpenRouter: [Haiku](https://openrouter.ai/anthropic/claude-haiku-4.5),
[3-small](https://openrouter.ai/openai/text-embedding-3-small).
Цены также проверены в публичных JSON-каталогах
[чат-моделей](https://openrouter.ai/api/v1/models) и
[эмбеддингов](https://openrouter.ai/api/v1/embeddings/models).
3-small по умолчанию выдаёт 1536 чисел — столько же требует наша БД.
[Документация OpenAI](https://developers.openai.com/api/docs/guides/embeddings).

**Цены Cloud.ru в обеих таблицах ниже взяты именно из тарифного PDF версии 261029:**
страницы 1, 6 и 8, последний столбец с НДС 22%; таблицы сверены визуально.
HTML тарифа и маркетинговые страницы расходятся с PDF по составу/порядку,
а местами и по обозначению входа/выхода. Для бюджета необходимо подтвердить
выбранную ставку в карточке модели или биллинге.
[PDF](https://cdn.cloud.ru/docs/legal/tariffs/evolution/current-version/foundation-models.pdf),
[HTML тарифа](https://cloud.ru/documents/tariffs/evolution/foundation-models).

Валюты не пересчитывались. Это ставки использования моделей, а не полный счёт
с комиссиями пополнения: у OpenRouter Standard отдельно указана комиссия покупки
кредитов 5,5%. Поэтому вывод «один поставщик дешевле другого» без курса и условий
оплаты не делается. [OpenRouter Pricing](https://openrouter.ai/pricing).

## Внутренние модели Cloud.ru

Для этой группы каталог указывает работу внутри инфраструктуры Cloud.ru.
Эти модели можно использовать через API, не разворачивая их веса на нашей VPS.
[Каталог FM](https://cloud.ru/docs/foundation-models/ug/topics/overview__available__models),
[доступ к API](https://cloud.ru/docs/foundation-models/ug/topics/api-ref).

| Роль | ID модели | Вход / выход, ₽ за 1 млн токенов с НДС 22% | Что оценивать для проекта |
|---|---|---:|---|
| Ответы | `openai/gpt-oss-120b` | 15,86 / 61 | Экономичный кандидат; проверить формат JSON, reasoning и задержку |
| Ответы | `ai-sage/GigaChat3-10B-A1.8B` | 12,20 / 12,20 | Ещё один бюджетный кандидат; отдельно проверить точность цитат |
| Ответы | `Qwen/Qwen3.6-35B-A3B` | 219,60 / 329,40 | Кандидат для сравнения с Haiku на наших вопросах |
| Ответы | `deepseek-ai/DeepSeek-V4-Pro` | 183 / 732 | Вариант DeepSeek в этом сервисе; проверить пользу reasoning для короткого ответа |
| Эмбеддинги | `BAAI/bge-m3` | 0,61 / — | Dense-вектор модели 1024, без обязательных query-инструкций |
| Эмбеддинги | `Qwen/Qwen3-Embedding-0.6B` | 0,854 / — | Модель поддерживает до 1024 измерений и инструкции для поиска |

Характеристики эмбеддеров подтверждены авторами:
[BGE-M3](https://huggingface.co/BAAI/bge-m3),
[Qwen3-Embedding-0.6B](https://huggingface.co/Qwen/Qwen3-Embedding-0.6B).
Это свойства моделей, а не подтверждённый ответ endpoint конкретного проекта Cloud.ru.
Официальная статья Cloud.ru также подтверждает API-доступ к этим эмбеддерам.
[Эмбеддинги в Cloud.ru](https://cloud.ru/blog/embeddingi).

Низкая ставка, размер модели или большой контекст не доказывают лучшее качество
на русских материалах клиента. Для первого сравнения разумно взять gpt-oss-120b
и Qwen3.6; Haiku оставить контрольным вариантом. DeepSeek-V4-Pro включить,
если более простые варианты ошибаются на нужных вопросах. Для текущих коротких
чанков преимущество длинного контекста само по себе не является критерием выбора.
Это порядок отбора кандидатов, а не установленный рейтинг качества.

## Данные и гарантии

По описанию Cloud.ru внутренние модели не передают пользовательские данные наружу
и не сохраняют/не логируют их. Для внешних такой режим не заявлен. Действующие
условия отдельно исключают внешние модели из общего SLA; их обработка и доступность
зависят от внешнего провайдера. На дату проверки действует версия условий 260430;
будущая редакция 261116 вступает только 26.11.2026.
[Условия услуги](https://cloud.ru/documents/contracts/terms-of-service/evolution/foundation-models/description-foundation-models).
География моделей не определяет автоматически режим хранения данных нашего
приложения на VPS и сама по себе не подтверждает соответствие законодательству.

## Изменения в проекте

В `packages/rag/src/openrouter.ts` адрес шлюза — константа, один ключ используется
для `/chat/completions` и `/embeddings`; `constants.ts` и `config.ts` допускают только
нынешние две модели. Смены `.env` недостаточно.

**Сохранить те же модели через FM:** нужен адаптер endpoint/auth, переменные сервиса
и проверки совместимости. SQL-миграция не требуется лишь из-за смены шлюза.
Но до сохранения индекса надо подтвердить тот же encoder/version, размер 1536,
preprocessing, порядок батча и поисковую совместимость векторов. Сейчас клиент
не проверяет `embedding.index`, а полагается на порядок массива `data`.

**Перейти на внутренний BGE/Qwen:** новая embedding-модель требует переиндексации.
Для 1024 вместо 1536 нужны новая SQL-миграция колонки/индекса и обновление guards,
проб и тестов. Даже одинаковая размерность не разрешает смешивать разные encoder.
Порог сходства 0.40 требует новой калибровки.

Сохраняются квоты и последовательность `attempt + fsync → API → outcome`,
разделение арендаторов, проверка цитат и ответ «не знаю». Журнал сейчас хранит
общие tokens_actual, без отдельных входа/выхода и провайдера; для сравнения
фактической стоимости следует добавить раздельный usage и provider metadata.

## Контрактные проверки перед переносом

Base URL FM — `https://foundation-models.api.cloud.ru/v1/`.
Нужен отдельный ключ сервисного аккаунта с сервисом Foundation Models;
S3-ключи для этого не подходят.
[Аутентификация](https://cloud.ru/docs/foundation-models/ug/topics/api-ref__authentication).

Публичная [OpenAPI YAML](https://cloud.ru/docs/api/specs/foundation-models/ug/_downloads/f2949c1237d79b17b2df8e523e02a89a/openapi__foundation-models.yaml)
описывает models/chat, но не embeddings; enum `response_format.type` содержит
text/json_object, хотя рядом есть поля json_schema/strict и каталог заявляет
Structure Output. Это разрыв документации, а не доказательство отсутствия функции.
Поэтому конкретный маршрут нельзя считать совместимым до проверок:

1. Список моделей выбранного проекта и разрешённый embedding request из консоли.
2. Ответ строго по нашей JSON-схеме, пустой/неполный/ошибочный ответ, неизвестная цитата.
3. Обычный ответ до 400 токенов и startup-проба до 16; влияние reasoning и таймаут 20 с.
4. Эмбеддинги документов и вопросов: длина, нормализация, порядок/индексы батча.
5. Наш набор 20 известных и 20 отсутствующих в источниках вопросов: поиск, цитаты,
   корректный отказ, задержка и раздельная стоимость токенов; настройка порога.
6. 401/429/5xx/таймаут, ограниченные повторы с учётом каждой попытки.

## Выбор для дальнейшей работы

Если главное — единый российский поставщик и сохранение нынешних моделей,
начать с Haiku + 3-small через FM, учитывая внешний режим обработки.
Если главное — inference внутри Cloud.ru, начинать испытания с внутренних LLM
и BGE/Qwen-эмбеддера; это отдельная смена моделей и индекса. Выбирать лучше до
загрузки первых реальных источников.

Три агента отдельно проверили код, каталог/API и тарифы/ограничения; координатор
сопоставил выводы и визуально сверил тарифные таблицы. Ключи не использовались,
платные модельные вызовы не делались. Качество/задержка Cloud.ru для наших данных
ещё не измерены. Провайдер, приложение и окружение запуска не изменены.
