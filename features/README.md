## Процесс и модели

Feature-ADR из djd1m/dz-harness, актуальный установленный протокол и закреплённые project CLI; OpenSpec хранит дельты и задачи. Используются direct AQE pattern recall и встроенные collaboration-агенты, которые выполняют реальные задания. Установка MCP runtime сама по себе не означает выполнение всех его swarm-агентов.

Запрошенные модели: инвентаризация/ADR/архитектура — gpt-6.2-sol/high; будущий код — gpt-6.2-astra/high; independent QCSD — gpt-6.2-astra/high (quality/risk) и gpt-6.1-terra/high (testability). QE кода получит отдельные сессии с моделью, отличной от автора. Фактические внутренние метаданные провайдера, токены и цена исследовательских запусков не раскрываются инструментами и не реконструируются по догадке.

[Инструменты](process-setup-20261125.md), [независимый аудит](process-setup-independent-review.md), [команды](../tools/feature-process/README.md). Нативное исполнение hooks текущей сессией Codex не подтверждено. Используется явный запуск исполняемых гейтов; найденные обходы исправляются и повторно проверяются. GitHub CI не добавляется.
