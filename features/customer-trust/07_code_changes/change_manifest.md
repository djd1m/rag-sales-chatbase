# Реализация и передача итоговой сборки

Рабочая ветка: `feat/sufler-ux-customer-trust-20261125`. Базовый ref процесса остаётся `ba3959709716dc1426ed6de4bf66485bd6d2d3a6`. Реализация собрана и доступна в отдельном публичном демо. Основной сайт ещё не переключён; Step 8/9 ждут окончания измерений.

## Авторы и проверка

Три первоначальных автора получили полный literal-контекст штатного helper и отдельные допуски целей: UI, identity/legal/mail, billing/support. Запрошенная модель — `gpt-6.2-astra/high`. Нагрузочный прибор и независимые денежные проверки используют `gpt-6.2-sol/high`, UI проверяет `gpt-6.1-terra/high`; фактическая внутренняя маршрутизация провайдера отдельно не подтверждена. Реальный Claude roundtrip не состоялся из-за ограничения аккаунта; его ревью не приписывается.

После независимых находок исправлены: аттестация настоящего магазина до намерения; кеш успеха на неизменных credentials; повтор оплаты после холодного /me с проверкой абсолютного срока непосредственно до POST; привязка refund; поздний dispatch purchase mail; проверка и SRI закреплённых байт SDK; повтор recovery fragment в той же странице; надёжный retry и ошибки claim; высота области чата; копирование при отказе браузера; области нажатия поддержки; доступность восстановления только при настроенной почте. Решения и точные тесты записаны в Amendments обоих планов. Исходные условия и ошибочные промежуточные прогоны сохранены.

## Оставшиеся измерения и ограничения

Шесть сторон benchmark r4 завершились 25 ноября в 19:20 UTC с **FAIL**. Сравнительные медианы p95 прошли, однако первый запрос входа и загрузки в одной стороне эталона вернул незапланированный отказ. При принудительном таймауте checkout обе сборки возвращали общий код ошибки. Исходные данные, первоначальная оценка и отдельная исправленная оценка таймеров сохранены; ни одна не объявлена PASS.

В сборке Next независимо подтверждена причина checkout: instrumentation и маршрут содержали разные конструкторы исключений. Исправление использует отдельные неизменяемые собственные symbol-маркеры на настоящих Error; сходные имена и JSON не принимаются. Тест двух независимо вычисленных модулей воспроизвёл отказ до исправления; после него все 24 billing unit-теста прошли. Другой reviewer независимо перепроверил границу.

Прибор v3 выполняет один одинаковый безопасный POST с пустым телом login до запуска таймера и требует 422 invalid: это подтверждает готовность Redis без создания сессии и обращения к провайдеру. Ни один измеряемый запрос не удаляется. Общий код ошибки замороженного эталона допускается только на точном принудительном таймауте и с независимо прочитанным исходным незавершённым intent. Новая сборка обязана вернуть типизированный код с тем же intent. Все 28 контрольных тестов прошли, включая 10 дополнительных проверок отказа прибора.

Новая серверная сборка, отдельный настоящий checkout timeout/retry и повтор всех трёх пар ещё должны пройти итоговые проверки. В отдельных копиях выполняется V8-инструментирование; его влияние на временные утверждения регистрируется отдельно и не является успешным NFR-замером. Проценты покрытия пока не установлены. Нативная Step-8 convergence и финальный Fleet QE ещё не закрыты.

Настоящие почта, новая оплата и чат поддержки выключены до добавления ключей и отдельной проверки готовности. Закреплённый SDK — доверенный код приложения, а не изолированный browser principal. Идемпотентность Resend требует непрерывности того же аккаунта провайдера; глобальный exactly-once при смене аккаунта не заявлен. История сторонних сервисов не входит в обещание локального erasure. Исследование тарифов с пятью участниками остаётся отдельно и не проводилось.

GitHub CI не добавлялся по решению владельца. Chromium работает только в выделенном контейнере; WebKit не устанавливался. Автоматическое исполнение native Codex hooks в этой среде не подтверждено: реальные локальные K1/K2, допуски, OpenSpec и convergence вызываются явно. Серверные секреты и исходные приватные журналы в Git не публикуются.
